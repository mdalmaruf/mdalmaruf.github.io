## Overview

ESOps investigates an AI-assisted delivery pipeline for embedded systems. The goal is to connect software understanding and reuse with disciplined testing, deployment, and assurance activities.

## Research themes

- AI-assisted feature and requirement discovery
- Embedded software testing and continuous integration
- Hardware-aware delivery pipelines
- Safety and certification evidence across software changes

The project is under active development. See the [NEST Research Lab project page](https://nestresearchlab.ca/projects) for the latest lab-level description.
